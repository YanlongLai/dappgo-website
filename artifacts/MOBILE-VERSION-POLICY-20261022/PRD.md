# Mobile version support policy

Owner request: ship US Stocks, TW Stocks and Options Explorer at the shared marketing version 1.6.0 on iOS and Android. That version and later versions are supported; failed verification blocks app use and offers retry. Complete testing, merge, submit both stores and clean only this task's completed worktrees.

Scope: publish a small anonymous HTTPS policy at the existing official website. All six application/platform entries begin at 1.6.0. Clients use native package identity and version, and fixed store destinations. This contract does not retroactively affect old clients lacking the gate.

Acceptance: schema/identity tests, all three consumer suites, independent review, exact merged revision and anonymous deployed JSON readback. Future increases require actual store availability per platform and territory. Rollback restores a previously verified policy under a new revision.
