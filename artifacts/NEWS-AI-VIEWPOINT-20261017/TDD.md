# Technical design

Select only the report-level `ai_commentary` / `ai_commentary_en` ticker key as the company view. Preserve legacy scalar payload support for all-market selection only. Optional `ticker_data[*].news_commentary*` must never replace the company view. If `news_ai_quality.status` is accepted, a bounded selected publisher quotation or new source-specific summary may appear below it, explicitly labelled publisher context. An explicitly empty curated summary suppresses the legacy quotation fallback, preventing an unrelated peer story from reappearing. Rejected plans show no context. A validated article URL appears beside the attributed account in the same browser tab, so Back restores the News filter. Prefer concise all-market summary fields; otherwise take only the matching report summary's first paragraph. Keep text escaping. Add fixture coverage for source attribution, US quote-first collision, TW mapped commentary, locale isolation, unrelated-source abstention, unknown source recap and no-analysis abstention. Version all changed static assets together. Deployment is the website's static News asset, independent of engine report publication.
