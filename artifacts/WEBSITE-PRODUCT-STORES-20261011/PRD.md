# PRD — Platform-aware DappGo app downloads

## User outcome

Visitors should immediately understand which DappGo apps are available on Android and iOS, open the correct store with one click, and never mistake an unavailable platform for a broken link.

## Experience

- Keep the existing DappGo product-first visual language, bilingual toggle and light/dark theme.
- Use the supplied Google Play/App Store artwork as local, consistently scaled store badges.
- Show both platform rows on every app card: US Stocks, TW Stocks, Options Explorer and Number Merge.
- Use real anchors only for verified store listings.
- Show `Coming soon` / `即將推出` as a muted, non-focusable disabled badge where no verified iOS listing exists.
- Keep the News web destination separate from app-store choices.

## Acceptance

The user can reach all four Android listings, TW Stocks and Options Explorer iOS listings, and the four web products. Missing US Stocks and Number Merge iOS listings are visibly unavailable without a clickable dead control. The layout remains usable at 360px and desktop widths.
