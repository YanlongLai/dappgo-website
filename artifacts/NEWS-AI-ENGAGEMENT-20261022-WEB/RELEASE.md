# Scoped release runbook

Authority: explicit Owner request for new feature worktrees, AI disclosure/skeleton and Cloudflare metrics, with same-session News merge/deploy/cleanup authority. Other sessions, fullscreen ad unlock, IAM/billing changes and mobile store publication are excluded. Website is registered; News App discovery is degraded and explicit Owner scope is recorded.

1. Complete web quality, native tests/typecheck, separate iOS and Android exports, diff/secret scans and independent read-only review of immutable source commits.
2. Check coordinator ownership before commit, push, PR, merge and deployment. Create normal GitHub PRs, inspect actual CI, merge, then fast-forward clean default checkouts.
3. Freeze the merged website SHA and previous News Pages deployment 03daa0eb-b51d-4d52-ae6a-34e110071612. Deploy only news/ to Pages project dappgo-news, recording exact commit and deployment ID. D1 migration is additive; do not delete D1 on source rollback.
4. Read back production deployment/binding, US/TW routes/assets, data, disclosure and analytics. Verify deduplicated web/iOS/Android events using exact labelled event IDs, then delete only those verification rows and rerun the Owner report. Preserve genuine events.
5. Native merge prepares the next app build; expo-crypto requires a new native build. No claim that installed iOS/Android versions have changed. Before any later store release review both store privacy/data-safety declarations for first-party product interactions independently.
6. Preserve final evidence outside worktrees, stop local preview processes, remove generated outputs, verify clean status and merged ancestry, release both claims from their owning checkouts, then remove only this task's worktrees/branches. Recheck default checkouts clean and aligned.

Future ad gating remains an idea only. Any later implementation must check buyout/ad-free entitlement before an ad requirement; no ad gate or hook is added here.
