# Design and bounded execution

Risk: R3 (cross-repository event contract plus authorized Cloudflare setup/News release). One new named feature worktree per repository, existing default heads; bounded coordinator claims before code edits.

UI: collapsed disclosure contains stock/scope, AI title, one tap/click instruction and a small animated chevron. Native uses measured pane width, web uses existing typography/breakpoints. Open state persists across language changes and same-scope refresh, resets on scope switch. Loading exists only while report fetch is actually active. Keep AI analysis sourced from published commentary; no model/provider requests are introduced.

Cloudflare: use a scoped D1 engagement database and Pages Function, because Cloudflare Web Analytics page views are not stock click events. Anonymous ID rotates daily (UTC), persisted only for that day; server hashes/partitions it by day. Counts mean panel-open actions and distinct daily anonymous browser/install IDs, not verified people or cross-device identity. Both platforms expose an analytics opt-out; web additionally respects DNT/GPC. Ingestion has a small JSON size cap, enum/ticker/UUID checks, parameterized SQL, origin checks for browser requests, idempotent event ID, short timeout and failure isolation from reading. CORS is restricted to the known News web host (native requests have no browser Origin). No secrets in clients and no public report API. Owner reports run via Wrangler D1 SQL under existing auth; include stock/market/platform and daily visitor totals. Each accepted write removes at most 100 events older than 90 days, using an index. This is on-write cleanup, not guaranteed 90-day expiration when traffic stops or a backlog exists; no daemon is added.

Tests: event schema/origin/size/idempotence/opt-out; open vs close/rerender and scope reset; waiting<300ms, skeleton and 8s slow path; reduced motion; responsive 320/390/768/1440 browser screenshots; native component effects/tests, typecheck and separate iOS/Android exports. Existing website quality/ads contract stays required. Obtain independent read-only review for frozen revisions before promotion, inspect CI and secret scan, release exact merged News source, confirm production metrics with labelled verification events and remove them afterward. Freeze rollback deployment/database migration (additive); source rollback leaves inert D1 data.

Stop conditions: scope/claim conflict, revoked authority, required IAM/billing change or unavailable production permission. Prepare concrete verified implementation before requesting any missing Owner action. No new tokens, IAM or billing changes.
