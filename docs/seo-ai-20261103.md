# SEO and AI homepage implementation record — 2026-11-03

Implementation is local to the requested feature branch. The original pulse data, CSP, advertising tags and analytics tags are preserved. No publication is part of this change.

## Behavior and source of truth

- `index.html` remains the English source page. `assets/home/home.js` owns the language dictionaries and shared pure card renderers.
- `node scripts/render-pulse-html.mjs` regenerates the English pulse regions, catalog-derived app JSON-LD, and the entire Traditional Chinese page. It performs no network calls and never changes `data/pulse.json`.
- `node scripts/build-zh-home.mjs` regenerates only the Chinese page. Both builders have a read-only `--check` mode.
- The canonical daily pulse build regenerates both HTML files even when its fetched data is unchanged. The verifier checks both snapshots. The bot no-op check and commit path list now include both pages; token validation, retries and push-rejection handling are preserved.
- Language is determined by the URL. The toggle is a normal anchor and records an explicit choice in `dg-lang`; there is no Accept-Language or browser-language redirect.
- Both no-JavaScript pages expose the three statistic values, per-market dates and coverage, equity regime summaries, named movers, options setups, source-linked headlines for both markets, source build time, and research disclaimers.
- App JSON-LD lists the four products with live stores. Platform labels derive from catalog store keys. Categories, offers, prices and ratings are omitted because the catalog supplies none.
- Taiwan placeholder labels use company names already present in `data/pulse.json`; no additional name map was introduced.
