# Website system improvement — first implementation

Canonical plan: dappgo-stocks-meta/docs/plans/WEB_SYSTEM_IMPROVEMENT_20261022.md.

The homepage now opens the working US research product from the first screen and offers direct News, Options and TW routes. News links back to the product family, has a keyboard skip link and one main heading, describes published news rather than claiming a live market, and identifies the market timezone beside timestamps. Data parsing, provider URLs, financial content, ads and consent configuration are unchanged.

The existing brand and genuine product screenshots are retained. Taste direction product-performs was selected because visitors need access to the real research tools; this is an incremental navigation repair, not a complete redesign. Existing stylistic findings are retained as later work rather than hidden.

Validation: website quality gate; bilingual News interaction checks; first-screen navigation and mobile layout in a real browser. Record outcomes in artifacts/WEB-SYSTEM-UX-20261022/EVIDENCE.md. Rollback: revert this source change and republish the previous verified static artifact.
